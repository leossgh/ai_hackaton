Each condition has its own exit code, so a script can tell them apart:

| Code      | Name                    | Condition                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
|-----------|-------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `0`       | `ok`                    | Success                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `1`       | `unclassified`          | An unexpected error                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `2`       | `usage`                 | An unknown command or flag, or a missing or invalid flag value                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `3`       | `not-authenticated`     | No registry and no stored login (run `foundry-toolkit login` or pass `--registry`), a stored login whose token has expired and can't renew, whose renewal Auth0 refuses, or a credential the registry rejects (log in again), a stored login whose registry names no host, or `whoami` finds no stored login                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `4`       | `not-entitled`          | Signed in, but the account isn't entitled to Foundry in that organization                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `5`       | `login-failed`          | The browser, Auth0, or federation step of `login`, or of an expired login's renewal, didn't complete, or the access token carries a registry access claim that's malformed or that this build can't read                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `6`       | `no-match`              | A `get` or `module describe` selection matched no artifact, in the registry or in `--from-archive`, or a `module describe --image` names no manifest                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `7`       | `ambiguous`             | A `get` or `module describe` selection matched more than one artifact, which the error lists                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `8`       | `registry`              | A registry or network request failed, as when the registry refuses a read without a credential                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `9`       | `output`                | Writing a listing, an artifact, an archive, the credential, or a Docker config failed, or foundry-toolkit refused to replace what's there: an existing `--to-archive` file; a `--to` that names a file or holds an entry the artifact would write; two of an artifact's files that land on one, as names that differ only in case do on a case-insensitive filesystem; a Docker host that another tool's credential helper or your own login serves on `docker configure`; or one that any helper or your own login serves on `docker static-auth`. Only the message separates the two                                                                                                                                                                                                                                                                                 |
| `10`      | `conflict`              | The tag to write already holds an artifact                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `11`      | `validation`            | An artifact breaks a rule of its kind. On `get`: an entry that's neither a folder nor a regular file, such as a link; a name with a `\`, a path element starting with `.wh.`, one that Windows reads as other than a name (a `:`, a device name such as `CON`, a trailing dot or space), one that leaves `--to`, or one that repeats another; more than 50 GiB or 2^20 entries; an agent skill without a `SKILL.md` at its top; or a workflow source with an invalid or missing composition, manifest, or contracts, or with generated wrappers, `lib/FoundryInputs.groovy`, an old lock, `tasks.config`, or `resources.json`. On `module list`, a `tasks` annotation that doesn't parse. On `module describe`, a missing or malformed contract, or an index whose platform images differ in Foundry contract or metadata, or that nests another                                              |
| `12`      | `unverified`            | On `get` or `module describe`, or on `list` for every artifact the filters match, no signature verifies against the signing key, whose source the error names: it's missing, from another key, or over another digest                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `13`      | `archive`               | A `--from-archive` archive is unreadable, malformed, or tampered with                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `130`     | `interrupted`           | `SIGINT` or `SIGTERM` cancelled the work in flight, which unwound cleanly                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |

- The codes and their names never change. Every error goes to stderr; see
  [Diagnostics on stderr](#diagnostics-on-stderr).
- A usage error names every problem of the flags at once, by flag name,
  whatever their order: each flag given twice, each value that its flag
  refuses, naming the variable when the value came from one, and each
  combination of flags that can't work, such as `--password` beside
  `--password-stdin`. An unknown flag or argument stops the parse, so its
  error comes alone.
- A usage error prints the command's usage before the error, and leaves stdout
  empty. It leaves out the usage where it can't help, as for a `--policy`
  file that doesn't parse, and under `--log-format json`.
- A second `SIGINT` or `SIGTERM` ends the process at once, should the
  unwinding stall.
- `foundry-toolkit docker credential`, which Docker calls, follows the
  credential-helper protocol instead, and exits `1` on any error.
